# Task 2 — Network Security & Scanning

## Objective
Learn reconnaissance, scanning, vulnerability assessment, firewall basics, and packet analysis in an authorized lab.

## Workflow
1. Passive reconnaissance of a permitted test environment.
2. Active discovery of the lab target.
3. TCP/UDP service identification.
4. Service/version inventory.
5. Vulnerability assessment.
6. Wireshark traffic review.
7. Firewall rule validation.
8. Findings and mitigation report.

## Safe evidence table
| Evidence | What to capture | Result |
|---|---|---|
| Host discovery | Lab target discovered | Replace with screenshot |
| Service inventory | Authorized open services | Replace with Nmap output |
| Vulnerability assessment | Severity summary | Replace with scanner report |
| Packet analysis | HTTP/FTP/DNS lab traffic | Replace with Wireshark screenshot |
| Firewall | Allowed/blocked test port | Replace with screenshot |

## Findings format
Finding:
Asset:
Evidence:
Risk:
Impact:
Recommended mitigation:
Verification method:

## Mitigation examples
- Disable unnecessary services.
- Restrict management ports.
- Apply patches.
- Use encrypted protocols.
- Segment sensitive systems.
- Monitor repeated connection attempts.
